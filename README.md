# ربات فروش اکسپرت (پرداخت خودکار با USDT)

این ربات یه فروشگاه ساده توی تلگرامه. مشتری روی «خرید» می‌زنه، ربات یه مبلغ
دقیق USDT بهش نشون می‌ده، مشتری پول رو به کیف پولت واریز می‌کنه، و ربات
خودش با چک‌کردن بلاکچین (شبکه ترون / TRC20) تایید می‌کنه که پول اومده.
بعدش به تو (ادمین) پیام می‌ده که فایل اکسپرت رو دستی برای مشتری بفرستی.

هیچ نیازی به دانش برنامه‌نویسی نداری، فقط این مراحل رو دنبال کن.

## قدم ۱: ساخت ربات تلگرام و گرفتن توکن
۱. توی تلگرام برو سراغ [@BotFather](https://t.me/BotFather)
۲. دستور `/newbot` رو بزن و اسم و یوزرنیم دلخواه برای ربات انتخاب کن
۳. یه توکن بهت می‌ده شبیه این: `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`
   این رو جایی کپی کن، بعداً لازمت می‌شه

## قدم ۲: گرفتن آیدی عددی تلگرام خودت
۱. برو سراغ [@userinfobot](https://t.me/userinfobot)
۲. بهش پیام بده، یه عدد به اسم ID بهت می‌ده - همون رو کپی کن

## قدم ۳: آماده‌کردن کیف پول USDT
باید یه آدرس کیف پول USDT روی **شبکه TRC20 (ترون)** داشته باشی، چون این
ربات فقط این شبکه رو چک می‌کنه (کارمزدش کمه و رایج‌ترین شبکه‌ست).
می‌تونی از صرافی‌هایی مثل Binance یا کیف پول‌هایی مثل Trust Wallet آدرس
USDT-TRC20 بگیری. فقط آدرس رو لازم داری، نه کلید خصوصی.

## قدم ۴: بالا آوردن ربات روی هاست رایگان (Railway)
۱. یه اکانت روی [railway.app](https://railway.app) بساز (می‌تونی با گیت‌هاب وارد شی)
۲. یه پروژه جدید بساز و فایل‌های همین پوشه رو توش آپلود کن
   (ساده‌ترین راه: این پوشه رو توی یه ریپازیتوری گیت‌هاب بذار و Railway رو
   بهش وصل کن؛ Railway خودش راهنمای آپلود مستقیم هم داره)
۳. توی تنظیمات پروژه (بخش Variables) این مقادیر رو وارد کن:
   - `BOT_TOKEN` = توکنی که از BotFather گرفتی
   - `ADMIN_ID` = آیدی عددی خودت
   - `WALLET_ADDRESS` = آدرس کیف پول USDT (TRC20) خودت
   - `PRICE` = قیمت اکسپرت (مثلاً 50)
۴. Railway به‌صورت خودکار دستور `npm install` و بعد `npm start` رو اجرا
   می‌کنه و ربات روشن می‌مونه

## قدم ۵: تست
۱. توی تلگرام برو سراغ ربات خودت و `/start` بزن
۲. روی «خرید اکسپرت» بزن، مبلغ رو ببین
۳. یه مبلغ آزمایشی کوچیک واریز کن و روی «پرداخت کردم» بزن تا ببینی تایید
   خودکار درست کار می‌کنه

## نکات مهم
- این ربات فقط **USDT روی شبکه TRC20** رو چک می‌کنه؛ اگه مشتری با شبکه یا
  توکن دیگه‌ای بفرسته، شناسایی نمی‌شه.
- مبلغ هر سفارش کمی متفاوته (مثلاً 50.137 به‌جای 50) تا ربات بفهمه کدوم
  مشتری واریز کرده، چون همه به یه آدرس واریز می‌کنن؛ به مشتری بگو دقیقاً
  همون عدد رو واریز کنه.
- تحویل فایل اکسپرت دستیه: وقتی ربات بهت پیام داد که پرداخت تایید شده،
  خودت باید فایل رو برای مشتری بفرستی.
- سفارش‌ها توی فایل `orders.json` ذخیره می‌شن.
